## 2. Summary Decision Framework

| Decision Type | Target Elements | Core Architectural Reason |
| :--- | :--- | :--- |
| **ADOPT** | High-contrast primary CTA, Secondary scroll anchor, Accessible tabbed preview cards, Accessible accordion FAQ, Native smooth scrolling. | Essential for direct usability, conversion into `/app`, high information density, and 100% WCAG accessibility compliance. |
| **ADAPT** | Archival folder index tabs, Low-profile 48px header, Pinned paperclip artifacts, SVG support trail draw, Tactile card lift. | Infuses authentic Mary Colter / Mr. Panda tactile materiality into our custom Alliance India notebook design while keeping code 100% lightweight CSS/SVG. |
| **REJECT** | 3D canvas mouse-tracking, Drag-and-drop horizontal diorama, Audio sound effects, Scroll-jacking libraries, Heavy WebGL runtimes. | Incompatible with low-cost field Android phones, battery preservation, screen readers, and offline field reliability. |
| **DESKTOP-ONLY INSPIRATION** | Multi-plane asymmetric desktop spread with overlapping dossier sheets and side index tabs. | Elevated on large viewports (1440px/1280px) for maximum art direction, but deliberately refactored into an ergonomic single-column vertical flow on mobile (390px/360px). |
